How to add it

Paste the connector URL from the top of the page. No sign-in is needed, and every tool is read-only.

Claude.ai

Settings → Connectors → Add custom connector, then paste the URL.

Claude Code

ChatGPT

Settings → Connectors → Advanced → enable Developer mode, then create a connector with the URL (no authentication).

Then try asking

  • I want to fully focus on sessions about AI for business success. Make me an agenda for all three days.
  • What should I see on Monday about Oracle Integration, GoldenGate and MCP?
  • Can I walk from my 14:00 session (LRN1128) to the 15:15 one (LRN2162) without being late?
  • Build me a day plan for Tuesday around AI agents, with lunch and time to network.
